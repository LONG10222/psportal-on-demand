# 流量、订阅与在线升级

星渡路由器插件 0.4.0 开始支持此页面。已有 opkg 安装升级一次后，后续可以直接在管理页完成更新。

## 看流量

游戏、星渡两个页面共用入口统计。公网、局域网分别显示上传 / 下载速度和累计量，每两秒刷新页面数据。速度以设备为参照：上传是设备发往目标的数据，下载是目标返回设备的数据。

只统计经过手动 HTTP 代理入口的请求。局域网指请求目标为私有局域网地址；公网包括代理和直连的公网请求，不能把“公网”理解为“全部走了订阅”。流量包含 HTTP/TLS 数据，不包括链路层、TCP 重传等开销。累计量从入口服务启动算起，重启或升级后归零；切换页面不清零。

页面不会扫描全家设备、抓包、测速或唤醒休眠核心。入口不可用时显示横线，不沿用旧速度。

## 看订阅

显示所用订阅的名称、上传 / 下载账户用量、总量、剩余量、到期时间和剩余天数。游戏模式读取已选订阅；星渡读取当前 OpenClash 配置对应的订阅。没有匹配的配置名称时列出已启用的 OpenClash 订阅，分别显示，不合并套餐。

点击 **刷新订阅信息** 从已保存的 HTTPS 地址读取 `Subscription-Userinfo`，不替换节点、不改变代理开关，也不会启动核心。同一订阅 30 秒内不重复请求。缓存保留在本机，刷新失败继续显示上次数据及失败状态；常规页面轮询只读缓存。

服务商未提供的字段显示“未提供”。`total=0` 按不限量显示，`expire=0` 显示长期有效；没有过期字段不推断为永久。账户用量可能包含其他设备，与此入口累计量不同。缓存和日期以路由器、浏览器的当前时间显示。

## 在页面升级

1. 点击右上角 **检查更新**。
2. 有适用的正式路由器版本时，点击 **一键安装更新**。
3. 等待下载、校验、备份、依赖预检和安装完成，刷新页面。

无需下载到电脑再上传。安装任务在软路由后台运行，页面刷新不会中断安装。软件包包含星渡插件和配套鲜牛模块，不附带或替换 OpenClash 核心。只更新 opkg 管理的这两个软件包，不升级固件或其他插件。

代理地址、端口、订阅、MAC 备注和选择的模式保留；原来开启的游戏/星渡按保存状态恢复。安装前鲜牛会停止并确认暂停计时，更新后保持暂停。已有连接会短暂断开。

失败会显示错误，备份位于 `/etc/portalproxy-backups/update-*`。备份含私有配置，留在本机即可。不要用卸载插件的方式升级。

## 发行包约定

路由器只接受本仓库非草稿、非预发布的 `starpass-router-vX.Y.Z` Release，每版包含独立附件：

- `luci-app-starpass_X.Y.Z_all.ipk`，版本与 Release 一致。
- `xianniu-router_X.Y.Z_all.ipk`，配套模块版本可独立递增。
- 对应源码、许可证和校验文件，供人工核对与重新构建。

自动安装前核对 GitHub 附件 SHA-256、字节数、包内名称 / 版本 / 架构，并拒绝配套模块降级。桌面安装包、CI 测试归档和缺少摘要的附件不会被选中。网络失败不会被当作“已经是最新版”。
