## 评价

- macOS 简洁入口、真实设备来源 IP 统计、分组节点选择和停止入口已有较完整结构。
  直接订阅的外部 Mihomo 模式与关联既有代理分离，符合不同使用场景；关联模式仍由原客户端管理节点
- iOS 已有共享、节点、设备三页、中英文切换、内置节点适配器池和前台生命周期管理。
  订阅 URL 不持久化，保存配置使用文件保护及备份排除；套餐字段来源于服务器响应头
- 当前主要风险集中在异步操作与网络切换边界，而不是页面数量。本轮采用小范围修复，
  未替换用户的界面结构、引擎协议或系统网络设置
- iOS 仍不等同于 Android 完整核心模式：目前导入受支持的节点，不导入完整 Clash 分组／规则。
  iOS 必须前台且解锁；后台持续 LAN 共享尚未实现。HTTP/CONNECT 是 TCP 代理，不能据此承诺全部游戏 UDP

## 修复的缺陷与回归方式

1. **网络变化读取旧状态。** Combine 的 `@Published` 在 willSet 发布。
   原界面收到新快照却读取旧属性，可能漏掉第一次断网／IP 变化。
   改为模型接收发布值，测试首个断网、启动中改 IP、重复事件与重连不自动启动。
   多个物理接口／地址不再猜测；自动发现只接纳活跃接口。
2. **旧节点操作跨重启。** 节点队列与停止队列独立，原 UI 代际校验只保护显示，
   无法阻止旧命令进入新的原生全局引擎。新增控制器会话校验，停止先取消再排空操作队列。
   队列闸门测试覆盖旧 select/fastest、已经进入原生边界的操作和失败启动。
3. **停止后的套餐网络请求。** 原请求使用独立后台上下文，停止无法取消。
   iOS mobile 入口现只读取运行引擎的配置 URL，并复用该核心的取消上下文。
   保留 Android 使用的独立函数行为；测试请求前、HEAD/GET 过程中、HEAD→GET 边界与晚到响应。
4. **套餐信息新鲜度误导。** 显示获取时间及非实时标签；空／不可用响应保持未知，
   新启动和清除配置时移除旧快照，缺失字段继续显示未提供，不编造流量或到期时间。
5. **macOS 自动发现选错网卡或代理。** 不再从缺失／VPN 默认路由回退猜测 en0，
   不再把 scutil 的嵌套作用域平铺覆盖全局代理；PAC/WPAD 和不活跃／歧义地址转为手动设置。
   受控输出包含常见嵌套、停用、别名、失败命令、非法端口及多接口情况。
6. **一键准备失败修改既有配置。** 网络与端口规划先完成再提交；导入失败不切换原有模式，
   下载完成后的最终网络检查也必须通过。回归使用实际 DesktopApp 方法和离线输入。

`@Published` 时序依据：[Apple Combine 文档](https://developer.apple.com/documentation/combine/published)。

## 验证范围与证据解释

本地环境为 Linux，无可用 Swift/Xcode 或 Go 编译器。Python 行为回归、iOS 结构守卫、
CI 辅助脚本、语法／空白检查在本地执行；Swift XCTest、原生 Go/race、真实 macOS 窗口与
包、iOS Simulator、未签名 iPhoneOS 编译通过本提交 GitHub Actions 执行。
不要把源码守卫等同于编译，也不要沿用旧提交的通过结果；最终提交 SHA、任务链接、
测试数与终态记录在本次草稿 PR。

新 macOS 回归在原实现上先出现失败，再验证修复。iOS 队列与网络快照测试属于确定性
模型／控制器测试；既有真实生成框架的 HTTP/CONNECT、拒绝来源地址、Stop/restart
测试仍保留并随 Apple CI 重跑。套餐取消测试使用可控传输与真实取消上下文，无真实订阅。

## 仍需实际设备验收

- iPhone/iPad 本地网络权限允许／拒绝、实际 Wi-Fi／个人热点切换、锁屏与前后台停止
- 真订阅的加密节点、Portal/PS5 会话、实际延迟与吞吐量
- macOS 真实多网卡、VPN、代理 App 组合及防火墙授权
- 用户自有签名身份下的 iOS 安装／升级，以及 macOS Developer ID、公证与 Gatekeeper

构建时不使用签名密钥，不创建替代身份；未签名设备 app 不可直接安装。
模拟器启动截图只证明对应空状态页面成功呈现，不证明完整设备接入或后台运行。
