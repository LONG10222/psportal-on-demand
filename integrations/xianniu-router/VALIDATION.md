# 验证范围

## 0.4.4

- Windows Python 3.12 和 N1 ARM64 Python 3.11：50 项受控测试通过。
- 页面 DOM 测试覆盖游戏列表、设备选择、启动参数、独立扫码轮询、明确登录状态、剩余时长格式、二维码失败后的重试和独立 60 秒余额刷新。
- N1 实机官方会员接口正常；归一化剩余秒数、试用秒数与官方原始字段逐项相等，两个余额不叠加。
- 时间单位观察：188 秒内官方 total_datetime 减少 188；没有公开实际余额或账户资料。
- 升级后针对 PlayStation HTTPS 与本机 UDP/STUN 复测通过；不等于游戏对战验收。
- 升级保留私有登录、现有设备方案、插件配置及原来的运行状态。无关网络配置未改动。

## 已有通道依据

0.4.3 在相同 N1 原生内核上完成真实官方微信登录、会员详情、官方暂停/恢复、服务重启复用登录、约 120 秒自动续期。PlayStation HTTPS、第二域名 HTTPS、Steam 商店直连、本机 SOCKS5 UDP/STUN 均有成功实测，续期后 TCP/UDP 再次通过。0.4.4 没有改变传输协议。

## 未验收

实际 PS5/PC/Switch 游戏对战、Wi-Fi HTTP 代理之外的设备 UDP 接管、NAT 类型、Windows 整机加速接管、N1 整机重启、长期令牌过期自动恢复及长时间性能尚未完成验收。

DOM 交互测试和静态资源检查不等于实际浏览器外观验收。官方密码登录仅有受控编码测试；不把入口存在当作所有登录方式实测完成。

本文件仅保存去标识化结论，不包含家庭网络标识、会员快照、凭据或私有原始日志。
