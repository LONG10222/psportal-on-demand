# 0.2.0

- 加入由 StarPass 固定版本源码适配的 HTTP / HTTPS CONNECT 入口，与现有鲜牛会话共用节点、线路凭据和自动续期。
- HTTP 只允许设备名单及软路由本机；拒绝局域网、回环及特殊用途的目标地址。IPv4 域名查询使用现有 LAN DNS，避免 OpenClash fake-IP 对入口判断的影响。
- LuCI 增加 HTTP 开关、监听 IPv4、端口与请求/拒绝计数；明确区分规则就绪和真实设备加速。
- 增加 SOCKS5 UDP 包计数；HTTP 随同主服务启停和清理。
- 新增分段/截断帧、HTTP/CONNECT、请求体、认证头清理、LAN DNS 与续期失败保护的测试。
- 升级保留现有账号私有配置与设备名单。本机升级将 HTTP 绑定到已有 N1 地址 192.168.31.222:10082；全新安装默认仅准备配置，不开启 HTTP。

未改变小米或 PS5 设置。HTTP 代理只能承载使用它的 TCP 流量，PS5 实体游戏、UDP 接入和 NAT 仍待验收。
