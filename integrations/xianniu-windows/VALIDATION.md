# 验证范围 0.1.0

本轮在 Windows x64、Python 3.12.14、PyInstaller 6.16.0 上构建；旧版 Windows 10 项、N1 历史结果不计入新实现测试数。

- 新 provider 17 项受控测试通过，涵盖会话归属、DPAPI、不选择设备拒绝、TCP 二进制、UDP 来源绑定/分片/私网拒绝、端口冲突回滚、续期失败关闭、停止与暂停及重启。
- 相邻路由模块本次 50 项回归通过；原星渡 portable 本次运行 594 项，其中 510 通过、84 跳过。未把跳过测试计为通过。
- 冻结 EXE 的 DPAPI、目录、Tcl 和真实 TLS context 冒烟通过。发现并修复本机 Python 的 SSL 运行时公有 CA 策略文件漏包；保留原策略和系统证书验证。
- GUI 源码实例初始化、48 条初始游戏列表、PS4/PS5 港服选择、启动按钮可见和关闭通过。后续原生窗口捕获恢复正常，已检查浅色双栏布局、设备卡片、自动获取线路和完整按钮可见。主界面只保留账号、设备、游戏与启停；会话归属、网络参数和详细边界移入设置。未重新进行真实扫码登录验收。
- N1 实际初始状态为已停止且官方 stop 确认，账号有效、计时暂停；与历史交接的运行状态不同。未启动或停止 N1 服务。
- 冻结 EXE 独立 start 后运行 160 秒。本机 Sony 与第二域名的 CONNECT HTTPS 证书校验成功，SOCKS5 TCP 成功，SOCKS5 UDP/STUN 随机 transaction ID 匹配成功。一次 120 秒自动续期后，以上各项再次成功。
- 字面 IPv4 TCP 目标失败：两次请求各产生一次 tcp_errors。不能把域名成功推广为所有游戏 IP 已兼容。
- 首轮外部 N1 向 Windows LAN 的 TCP 与 UDP 控制入口均超时。用户授权并完成系统提权后，已确认两个专用 Allow/Private 入站规则生效，限定安装版程序、选定来源和本机 LAN IP；未关闭防火墙。助手增加成功/失败回执，避免窗口退出后看不到结果。
- 第二轮使用实际安装目录的 EXE，运行 160 秒。本机与外部 N1 同时测试：Sony/第二域名 HTTPS、SOCKS5 TCP、UDP/STUN 均通过，120 秒自动续期后再次通过。运行记录核对 HTTP 与 SOCKS5 的来源均包含真实 N1；不是 Windows 自连 LAN 地址。
- 字面 IPv4 TCP 仍失败。另在自己拥有的短会话中对三个 HTTPS 目标检查地址编码变体；没有任何变体完成证书校验，未将推测协议改动加入产品。诊断结束官方 stop 与恢复暂停均确认。
- 结束时退出码 0，官方 stop 确认，归属记录清除，HTTP/SOCKS5 监听均关闭，官方会员计时恢复为原暂停状态，N1 保持停止。

第二轮真实通道计数：TCP 成功建连 12，TCP 错误 5，UDP 发送 4，UDP 错误 0，发送 14496 B、接收 69241 B。四次字面 IP 请求明确失败，另一次 TCP 错误尚未分类；不宣称零错误。每个失败都保留在 evidence.json；没有用网页成功代替游戏验收。

同一游戏会话下 Windows 与外部 N1 的显式代理并发已验证；不等于多台实体主机游戏并发。实际 PS5 港服游戏、完整主机 UDP 接管和 NAT 仍未验收。当前事实是“可安装的原生 provider 预览，本机与外部 LAN 的显式 TCP/UDP 及续期已验证”。

尚未验收：实体 PS5/PC/Switch 目标游戏对战、主机完整 UDP 接管与 NAT、PC 应用透明捕获、同账号多游戏/多入口并发、断网及长期令牌恢复、正式签名发布审核。
