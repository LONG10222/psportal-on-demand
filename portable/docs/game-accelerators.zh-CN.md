# 星渡主程序：游戏与加速器集成预览

## 0.4.1：模式隔离与官方数据更新

修正 0.4.0 中“按钮只跳转、游戏入口常驻”的行为。选择“加速器模式”现在实际进入该模式，并使用已有可恢复的配置备份；只有该模式显示游戏导航。切换到游戏、混合或 Clash 模式后回到概览，恢复原订阅与设置，并隐藏游戏导航；即使直接要求显示 Games，也会返回概览。游戏页顶部可以直接切换模式。存在本页加速会话时要求先停止，避免跨模式遗留运行。启动器不再无条件传入 `--page games`。侧栏显示 `v0.4.1`，用于确认实际运行构建。

游戏目录启动时读取已安装鲜牛官方客户端的公开 `gamedata/gamelist.xml`，游戏页处于活动且未加速时，每 60 秒检查来源文件是否变化，变化后自动同步新游戏、区服与图标信息。保持搜索、收藏和仍有效的选择；文件不变不重复写缓存。客户端写入中、文件损坏或来源缺失时保留上一次有效目录并显示缓存状态。它跟随已安装客户端的目录更新，不把缓存标为鲜牛云端最新，也不会代替官方更新器下载/执行新程序。

线路由 `/client/accelerate/linelist` 动态读取：选游戏/区服时查询；空闲时每 60 秒刷新当前所选方案；一键启动前若线路超过 60 秒则先重新获取。设置中的“同步游戏与线路”可立即检查。加速运行时不更换正在使用的游戏、区服或线路；停止后继续同步。线路查询不调用 start/recovery 或恢复计时。

本机实测公开目录 3018 项，连续两次 Steam 线路读取均实际请求官方接口；另有受控测试验证官方文件新增游戏/区服会进入界面、线路响应变化可替换旧列表、损坏更新不覆盖有效缓存。此次没有启动付费加速或重新进行网络流量验收。

## 0.4.0：简洁的一键入口

概览中的“加速器模式”按钮直接打开同窗口游戏库，与左侧“游戏”入口一致。这个导航动作不切换底层代理模式，也不改写原订阅、LAN 地址、节点或配置文件；旧的标准 HTTP/SOCKS5 联动入口仍保留在高级路径中。已保存为旧 accelerator 模式的启动配置默认进入游戏页。

主界面保留账号、分类/搜索、游戏卡片、已选游戏以及一个“一键加速”按钮。区服/线路默认收起，可展开修改；设备、账号刷新、目录同步及网络参数放入“设置”。UU/雷神客户端入口移到“更多”，本轮优先鲜牛。

首次需自行微信授权，并确认同账号其他会话已停止。以后选游戏、点击“一键加速”即可沿用保存的区服，自动加载官方可用线路；等待中可以取消，取消或换游戏后的迟到结果不会启动加速。线路尚未读取完成时不要求用户再次点击；没有可用线路或读取失败时会停止准备，不启动付费会话。自动选择不代表测得了最低延迟。

运行后同一个按钮变为“停止加速”。自有 managed 会话会停止并申请暂停计时；复用会话只停止本页共享。关闭简洁页面同样仅清理本页会话。暂停失败保留错误提示，不把未确认状态写成已暂停，也不会卡在反复退出中。选择 Steam 商店/社区时，本次通道关闭商店直连例外，其他模式配置保留。

“一键”指准备和开启鲜牛显式代理通道；应用/设备仍需接入该代理，不代表已安装透明网络驱动或自动接管所有 PC/主机游戏 UDP。主界面保留简短代理/UDP 状态，详细说明放入设置。此次仅做 UI 与受控行为回归、冻结程序真实入口检查，没有重新开始付费会话或扩大先前的网络验收结论。

在星渡左侧点击“游戏”，直接进入同一个窗口中的加速器工作区。它是原 `PSPortalProxy` 主程序的一部分，不通过启动独立鲜牛 EXE 来伪装集成。原有概览、订阅、节点策略、规则、局域网共享、日志、游戏/混合/Clash 模式及配置格式保留。

## 两种接入

| 加速器 | 内置 provider | 已安装客户端联动 | 本轮验证边界 |
|---|---|---|---|
| 鲜牛 | 官方登录、时长、完整目录、区服/线路与已有原生 TCP/UDP | 读取公开安装信息与客户端游戏 XML | 目录和显式代理传输已有记录；字面 IP TCP、完整主机 UDP/NAT 仍有限制 |
| 网易 UU | 尚未取得可验证的公开嵌入引擎/账号接口 | 识别卸载项、归属明确的进程和 EXE；可打开官方客户端 | 本机未安装，检测规则仅做受控测试；未声称已读取 UU 游戏库或转发游戏 |
| 雷神 | 尚未取得可验证的公开嵌入引擎/账号接口 | 识别卸载项、归属明确的进程和 EXE；可打开官方客户端 | 本机未安装，检测规则仅做受控测试；未声称已读取雷神游戏库或转发游戏 |

这套注册表明确区分安装、运行、公开目录读取、账号、传输及实际流量接管。增加品牌描述不等于完成其内核适配。切换到 UU 或雷神不会把鲜牛的游戏库、余额或会话当作该品牌的数据。未来接入器应先补充真实来源和协议验证，再打开对应能力。

用户选择“标准代理入口”时，进入原有独立加速器模式，按真实 HTTP/SOCKS5 握手与 TLS 验证。该旧模式仍限制为 Steam 网页 TCP，不能推广成任意品牌的全游戏 UDP 接管。没有从进程运行或开放端口推断游戏已经加速。

## 鲜牛页面

保留 3018 项公开官方目录、图标、分页、分类、收藏、最近选择以及每游戏区服/线路方案。页面以惰性方式创建；仅浏览和读取线路不 start/stop，也不恢复会员计时。账号沿用当前用户 DPAPI 私有存储，与正常星渡订阅分开。

独立鲜牛预览和主程序共用这份账号存储的实例锁。先关闭独立预览，再在主程序中使用；不会同时启动两份相同账号的管理界面。切换品牌前要求停止本页正在运行的加速。关闭主窗口会等待本页自己的监听和会话停止；不会接管或停止其他入口的会话。

## 保护既有功能

- “游戏”是新增导航页。打开和离开它不改变原 product_mode、订阅、来源、节点偏好或配置字节。
- 页面只使用 `SPGame.*` 样式，不切换主窗口主题、不重写主窗口标题或退出处理。快捷键只在该页面激活。
- 主窗口原启动/停止栏仅在游戏页隐藏，离开后恢复，避免误把原模式的按钮当作游戏 provider 的按钮。原运行实例的生命周期保持独立。
- 新入站助手是可选、需用户确认提权的步骤，限定主程序、私有 LAN 地址与选定设备；不会自动修改 DHCP、路由、网关、DNS、ARP 或 Windows 系统代理。

运行源码：安装 `portable/requirements-build.txt`，在 `portable` 执行 `python -m portalproxy.desktop --page games`。完整构建仍走 `portable/build.py`，包含原主程序、鲜牛模块、公开目录和所需许可。预览启动器使用 `%LOCALAPPDATA%\StarPassGamesPreview\config.json`；日常配置不被预览覆盖。

## 0.3.1：微信二维码与安卓隔离复测

官方二维码当前返回 JPEG。已改用 Pillow 解码 JPEG/PNG，再显示到 Tk，避免原生 Tk 图片加载失败；获取/轮询失败会在登录窗口中提示并提供重新获取。图片或控件回调异常不再中断页面事件泵，避免登录失败后无法正常退出。真正的扫码、微信授权和额外验证仍由用户完成。

2026-10-25 使用本机专用 MuMu `StarPassValidation` 实例及无账号的 Android instrumentation 测试应用复测源码 provider。宿主机防火墙不足以阻断模拟器通过 NAT 到电脑其他 loopback 代理，最初的负向探测因此拒绝验收。补充客体 IPv4/IPv6 OUTPUT 限制后，只保留 `10.0.2.2:18082` HTTP 测试入口、客体 loopback 与已建立的 ADB 回复；外网 IPv4/IPv6 TCP、直连 DNS、电脑 Clash 入口均被实际探测拒绝。

选择鲜牛 Steam 商店/社区（游戏 12、区服 154、线路 120），并在测试配置中明确关闭 `steam_store_direct`。安卓应用通过系统 HTTP 代理访问 Steam 商店和公开 Web API，两项 HTTPS 均返回 200、使用默认信任链和主机名校验；provider 记录 2 条原生 TCP、0 条错误，没有直连计数。停止 provider 后，两项请求均失败，负向隔离测试在加速前和加速中均通过。

该结果验证安卓 Wi-Fi/NAT 下的 Steam HTTPS 代理链路与断路行为，不是 Steam 原生客户端、实际游戏 UDP、PS5 NAT、Wi-Fi 手机现场或新冻结程序传输的验收。测试后官方 stop 与暂停均确认，监听关闭，模拟器退出，临时 APK 卸载，5 个代理键恢复，测试实例 root 开关恢复关闭，专用宿主防火墙规则移除。
