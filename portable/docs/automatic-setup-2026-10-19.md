# Windows 自动配置与 Clash 套餐展示验证 — 2026-10-19

## 本轮行为

- 没有本地订阅、待导入链接时，底部“启动共享”自动复用检测到的回环 HTTP 系统代理。每次关联启动重新识别端口；未检测到代理时说明缺项，不静默启动过期地址。待导入新链接不会被旧关联覆盖。
- 独立模式优先保留明确选择的核心，然后寻找本程序托管目录、打包程序旁 Mihomo、标准安装目录中的 Clash Verge 稳定版核心；不扫描任意 PATH，也不选 alpha。明确指定但已丢失的路径会提示修复。
- “自动配置核心”先复用发现的稳定核心，否则 Windows x64 下载官方固定版本并验证 SHA-256 后原子安装。并发点击只执行一次，失败保留原文件、提示重试或手动选择。下载或配置不会启动共享。
- Clash 独立卡片在自动关联场景置于首页前方，每 10 秒在后台读取一次当前订阅的本地缓存，展示上传、下载、已用/总额、剩余额度、到期日期、剩余天数、更新时间。缺少字段显示“未提供”；缓存明确标注为非实时，不冒充实时流速。
- 本机代理可识别但没有可用套餐缓存时，提示打开 Clash 更新订阅；“打开 Clash”启动标准目录中的 Clash Verge，找不到则打开官方发布页。节点和核心由原客户端管理。
- 独立订阅的额度与 Clash 缓存分开展示，不相互覆盖；启动后的首页仍可查看套餐信息。粘贴链接仍然一次导入生效，启动保持独立动作。
