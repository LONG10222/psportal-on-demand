星渡 StarPass

准备就绪，连接你的下一站。

  1. 保存配置

    填写允许接入的设备 IP。复用 OpenClash 时，订阅、节点和测速都在 OpenClash 管理。

  2. 启动共享

    启动会启用开机自启；停止会取消自启。保存不启动，应用只重启已经启用的共享。

  3. 设备接入

    在该设备的手动 HTTP 代理中填写路由器地址和端口，保留原有 IP、网关和 DNS。用完关闭设备代理。

监听就绪或有连接不代表外网成功。请先验证网页，再测试目标游戏功能。HTTP/TCP 共享不提供游戏 UDP 或全设备路由。

手动代理不是断网保护：部分安卓 HTTP 客户端在代理不可达时会回退直连，其他应用也可能忽略系统代理。

流量包含协议头；时长属于本次监听会话。节点延迟来自历史检查，不是游戏延迟。应用、停止和运行中更新订阅可能中断连接。

应用更新

右上角点击“检查更新”，发现新正式版后点击“一键安装更新”。软路由会下载并校验配套安装包、备份配置，再通过 opkg 覆盖升级。

现有代理地址、订阅、设备备注和模式选择均保留。安装时连接可能短暂中断；鲜牛先停止并暂停计时，更新后由你重新开启。配置备份保存在 /etc/portalproxy-backups。

此入口更新星渡插件与配套鲜牛模块。核心由 OpenClash 更新。源码安装及非 opkg 固件请使用发布页的对应安装方式。
